# Sub4Tokens merge and menu-bar modes

Agent Speed keeps the paired token-ring design and owns the former Customize Sub 4 Tokens functionality in the same executable. The upstream Agent Speed product version remains 1.8.0.

## Menu-bar/taskbar display modes

The existing three display choices apply immediately to both measured token readouts:

- Icon and value: the existing paired rings with centered sum / Agent-mean numbers.
- Icon only: two rings with no token numbers.
- Value only: sum / Agent-mean numbers in the same two positions, without ring strokes.

No separate token unit or TTFT is introduced in any of these layouts. The existing money-only mode retains its original layout. Windows implements the same three modes for horizontal and vertical taskbars.

The macOS settings preview uses the actual paired-ring painter for token mode, so it follows the same three choices rather than the old gauge-plus-unit sample.

## Merged balances

The source is the user's local `customize-sub-4-tokens` project under the archived 2026-09-25 Codex folder (base commit `7100f1d`, including its existing uncommitted admin-key/refresh-token changes). The original project is not modified or removed.

On macOS Agent Speed draws provider-name/balance text directly after the paired rings inside the same status item, separated by six points. There is no second independently positioned status item. Clicking the balance region opens the original 360-point balance controls; clicking the rings keeps the dashboard action, and secondary clicks retain the quick menu. Original currency symbols, selected/total/rotation modes, provider checkboxes, refresh button, polling interval, rotation interval, Admin API Key connection and legacy access/refresh-token fallback are preserved. Settings → Cost includes visibility and an action opening the same balance controls in an independent window, reachable even when macOS pushes the status item offscreen. Speed and balances share Agent Speed's application/login lifecycle; no subprocess or second background app is needed.

Migration copies only the six existing nonsecret preferences once from `com.hinaw.customize-sub-4-tokens` into Agent Speed's defaults: base URL, selected providers, display mode, refresh/rotation intervals and explicit-selection flag. Secrets retain their original Keychain service/account identities, are loaded only when the real application starts, and are never copied into preferences or documents. OS Keychain access rules still apply. Saving credentials reports failure instead of silently claiming success. The connection form uses drafts and applies them with Sync providers, so partial edits are not used by scheduled polling. A6API cookies remain in Sub2API.

On Windows the same API/currency/selection/rotation logic runs inside Agent Speed. Balance text immediately follows the speed rings/readout, before optional cost/network/intelligence blocks, including the vertical taskbar layout. The Sub 4 Tokens quick-menu action opens its provider/connection panel. Credentials use Windows Credential Manager, while nonsecret options are stored in `%LOCALAPPDATA%/AgentSpeed/subscription-balances.json`. There is no automatic transfer of macOS Keychain secrets to Windows.

Admin keys call the cached `GET /api/v1/admin/external-subscriptions/statuses` endpoint with `x-api-key`. Legacy tokens use Bearer authentication, refreshing once on 401/403 through `/api/v1/auth/refresh` and retaining the rotated pair. Providers and currencies are taken from the API; different currencies are never added together. Missing balances remain unknown, and rotation skips them. Explicit empty selection remains empty across relaunches. No balances or credentials are bundled in the repository.
